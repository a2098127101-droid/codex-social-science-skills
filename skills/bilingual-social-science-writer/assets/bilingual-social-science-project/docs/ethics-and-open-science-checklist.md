# Ethics and Open Science Checklist

## Ethics

- [ ] Does the project involve human participants?
- [ ] Does it use interview, survey, platform, administrative, or sensitive data?
- [ ] Is ethics approval or exemption required?
- [ ] Is informed consent needed?
- [ ] Are vulnerable groups involved?
- [ ] Are identifiers removed or protected?

## Transparency

- [ ] Are data sources documented?
- [ ] Are cleaning rules documented?
- [ ] Are analysis scripts reproducible?
- [ ] Are deviations from the original plan recorded?
- [ ] Are limitations stated without concealment?

## Sharing

- [ ] Can data be shared?
- [ ] If not, is the restriction explained?
- [ ] Can code be shared?
- [ ] Can synthetic or metadata-only documentation be shared?
